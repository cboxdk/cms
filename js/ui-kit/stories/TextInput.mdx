## Do and don't

- Do give every input a label, and say in the description what the value must be.
- Do set autoComplete where the browser can fill the value.
- Don't put instructions only inside the input; they disappear when the reader types.

## Accessibility

The keyboard and screen reader behaviour is described above and held by the stories' play functions, which run as tests in gate 7 with axe; every story is shown in the dark theme, in forced colours and in Danish.
