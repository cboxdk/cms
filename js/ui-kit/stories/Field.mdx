## Do and don't

- Do use it for a control the kit has no component for, and spread the control props on the control.
- Don't build the label, description and error yourself; the field joins them to the control.

## Accessibility

The keyboard and screen reader behaviour is described above and held by the stories' play functions, which run as tests in gate 7 with axe; every story is shown in the dark theme, in forced colours and in Danish.
