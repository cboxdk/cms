## Do and don't

- Do pass the actor's class and state where the reader needs them, such as in a list of grants.
- Don't make the chip the only place an actor's state is shown on its own page; use a Badge in the header there.

## Accessibility

The keyboard and screen reader behaviour is described above and held by the stories' play functions, which run as tests in gate 7 with axe; every story is shown in the dark theme, in forced colours and in Danish.
