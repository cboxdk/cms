# Getting started

Cbox CMS has no installer for applications yet. What there is to install today is the development environment of this repository: the services in Docker, the dependencies, and the workbench application the commands run in.

- [Installation](installation.md): the services, the dependencies, the dev database and the first run of the gates.
- [Serve the workbench and log in](first-login.md): the first member of staff, their access, and the panel at `http://127.0.0.1:8080/cms`.
- [Testing with the testkit](testing.md): the fakes of the contracts, the test suites and how to run them.

Once the environment runs, the [developers section](../developers/_index.md) explains how the code is organised and checked.
