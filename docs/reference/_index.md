# Reference

The pages in this section are written from the code by a script, and a gate fails when one differs from what the script writes. Do not edit them by hand.

- [Error reference](errors.md): every error code of the kernel, with its HTTP status, CLI exit code and MCP response, whether a retry makes sense, and what to do. `composer docs:errors` writes it from the error catalog.
